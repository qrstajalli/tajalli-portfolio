# Tajalli Us Samad — Developer Portfolio

A premium macOS-inspired interactive desktop portfolio website.

## Concept

An interactive personal operating-system desktop environment inspired by macOS and [MyOS](https://myos.framer.website/):
- **Desktop Environment**: Full viewport desktop with moody vertical-grain sapphire lighting and a subtle classic Macintosh "hello" script.
- **Top Menu Bar**: Authentic macOS translucent menu bar with Apple logo, TajalliOS title, standard application menus (File, Edit, View, Go, Window, Help), status icons (Search, Control Center, Wi-Fi, Battery), and a live compact local clock.
- **Desktop Application Icons**: High-resolution macOS squircles with selection, hover, smooth dragging, and double-click action handling:
  1. About Me
  2. Projects
  3. Hackathons
  4. Experience
  5. Skills
  6. Open Source
  7. Resume
  8. Contact
- **Bottom Dock**: Floating frosted-glass dock with distance-based hover magnification, application tooltips, open indicator dots, and integrated external channel links:
  - Finder
  - About
  - Projects
  - GitHub
  - LinkedIn
  - Figma
  - LeetCode
  - Mail
  - Resume

## Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Icons**: Custom vector macOS squircles + Lucide React
- **Styling**: Vanilla CSS with modern custom properties, glassmorphism acrylic blur, and responsive desktop layout

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
