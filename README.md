# Tajalli Us Samad — Developer Portfolio

An interactive Windows-inspired desktop portfolio workspace.

## Concept

Unlike a conventional scrolling portfolio, this project functions as an interactive personalized desktop environment:
- **Lock Screen**: Windows 11-style lock screen with user profile, clock, and PIN authentication. (Development PIN: `2026`).
- **Desktop Environment**: Clean wallpaper with 9 draggable, interactive portfolio folders.
- **Taskbar**: Fixed bottom Windows taskbar with Start menu, search flyout, pinned external channels, running window indicators, and live system tray clock/calendar.
- **Windows System**: Draggable, minimizable, maximizable, and closable windows with focus/z-index management.

## Tech Stack

- **Framework**: React 18 + TypeScript + Vite
- **Icons**: Lucide Icons + Custom SVGs
- **Styling**: Vanilla CSS with modern custom properties, glassmorphism acrylic blur, and responsive desktop layout

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
